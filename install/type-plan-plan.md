# Plan

A high-level planning document that captures raw human intention and maps it to downstream artifacts. Plans are upstream of specs, tasks, and increments — they bridge the gap between "what I want" and "what we build."

## Properties

| Property | Value |
|----------|-------|
| Tag | `#plan/plan` |
| Location | `Mesh/Types/Plans/` |
| Archive | `Mesh/Archive/Plans/` |
| Naming | `(Plan) NNN [Name].md` |
| Numbering | `flint helper type newnumber Plan` |
